# FlyingFootball
My repository for my new android game, Flying football. 
Originally designed to be my first android game and a spin-off of `Flappy Bird` with a football theme.
Started by following a [tutorial series on YouTube by gaseluta technology](https://www.youtube.com/playlist?list=PLxgX0Xe-eVYak1iBUEW7ES3e0fQfxOQw0) and then using my own ideas, knowledge of Java, and AI help to continue the development.
